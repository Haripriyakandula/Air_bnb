# Air_bnb
Singapore Airbnb Data Analysis using Python, Jupyter Notebook, and Machine Learning
# Singapore Airbnb DataDive

**Course:** CSDA 6010 – MC Analytics Practicum  
**Program:** Master's in Data Science  
**Tools:** Python, Jupyter Notebook, Pandas, NumPy, Matplotlib, Seaborn

## Project Overview

This project analyzes Singapore Airbnb listing data to understand accommodation pricing, room types, property availability, and customer reviews.

The analysis follows the CRISP-DM methodology, starting with data understanding, cleaning, and exploratory data analysis.

## Dataset

- Original listings: 3,208
- Cleaned listings: 2,728
- Original features: 90
- Completely empty features identified: 13

## Preliminary Findings

- Private rooms account for 55.28% of listings.
- Entire homes and apartments have a median price of $304.28.
- The overall median listing price is $202.77.
- The average customer rating among rated listings is approximately 4.53/5.
- The IQR method identified 134 potential price outliers.

## Project Status

Data cleaning and initial exploratory data analysis have been completed.

The next stage involves further statistical analysis and machine learning models for Airbnb price prediction.
